LPU CAMPUS NAVIGATOR — CAMPUS-WIDE PROTOTYPE
===========================================

FEATURES
- Campus starting point and destination fields.
- Suggestions for academic blocks, campus facilities, hostels and sports grounds.
- Validation rejects locations that do not match the campus-place pattern.
- Google Maps walking-directions request between the two campus-qualified locations.
- LPU 360 virtual tour button and direct external tour link (officially referenced tour URL: https://iviewd.com/lpu2/).

RUN
1. Extract this ZIP.
2. Open lpu_campus_navigator/index.html in a browser with internet access.
3. Choose a campus starting point and destination, then press Find campus route.
4. Use Open directions in Google Maps for walking directions.
5. Use Open LPU 360 Campus Tour if the embedded tour does not load.

IMPORTANT
This is a student prototype, not an official LPU navigation service. The suggested block numbers are generic searchable entries, not a verified complete list of LPU blocks. Add or edit the suggestions after checking the current campus directory. Google Maps may not have exact internal building pins or pedestrian paths; it may return incomplete or incorrect internal routes. Confirm with campus signage or university staff. The 360 tour is for visual exploration, not turn-by-turn navigation. An embedded third-party tour may block iframe display; the external Open button is provided as a fallback.
